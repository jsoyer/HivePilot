# Public-safe denylist
#
# Structural (non-sensitive) regex patterns that indicate un-genericized
# internal/org-specific content leaking into this PUBLIC repo. One pattern per
# line, `#` starts a comment (whole-line, or trailing after whitespace), blank
# lines are ignored. Patterns are compiled case-SENSITIVELY.
#
# SCOPES
# ------
# A `[scope]` header sets the scope for every pattern below it, until the next
# header. Unscoped lines default to `[any]`.
#
#   [any]      forbidden in every scanned file (engine code, prompts, docs,
#              config examples, web UI).
#   [prompts]  forbidden only in `prompts/` — text handed to an agent verbatim.
#              Use this for patterns that describe an INSTRUCTION to an agent
#              rather than a leaked identifier: the same string may legitimately
#              appear in engine code that IMPLEMENTS the integration.
#
# IMPORTANT: do NOT add real personal names here — this file is committed
# to a public repo, and enumerating names would re-leak them. Personal-name
# patterns (or any other sensitive-but-structural pattern maintainers don't
# want in a public file) belong in a PRIVATE, uncommitted file referenced
# via the PUBLIC_DENYLIST_EXTRA environment variable, e.g.:
#
#   PUBLIC_DENYLIST_EXTRA=~/.hivepilot-private/denylist.txt \
#     python scripts/check_public_safe.py
#
# That file is never committed to this repo. Every pattern in it is treated as
# `[any]` regardless of headers — a private pattern is private because the
# string must not appear ANYWHERE.

[any]
